# ADR-001：独立原创表现资源档

日期：2026-09-17。项目：tyj1987/MoxiangReborn。

用户明确要求重新创作地图、人物、动作、特效、物品、UI、音乐等资产，并以中国城市和景区为地图参考，保留武侠风格和玩法。用户已批准开始实施。

此决定覆盖旧路线图对新资源继续像素级复现的要求，但不授权随意更改玩法、数值、协议、原资源或将其他项目混入。

采用 moxiang-reart-v1 独立离线生产档，原 playdh-current 保留；新资产不得静默回退到旧素材。生产文件、依赖、校验和、玩法绑定、来源与验收状态必须登记。空绑定代表未完成，不自动猜测物品/技能/地图摆放 ID。

生成样本不启用客户端默认资源档，不部署、不合并、不创建正式发行版。发布需格式、玩法、视听、设备与来源验收，不能由文件存在或无画面解析测试代替。

CHX 按当前代码是 MOD/ANM 文本清单。交付必须包含实际原生载体，而不是把 GLB 改后缀。Map10 的数据身份已确认是嵩山，Map17 为兰州；地形参考应使用核验后的原包数据，不使用占位高度场冒充原轮廓。
