# MoxiangReborn 原创资产批次 01

范围仅为 `tyj1987/MoxiangReborn`。基线 `89a11b3653549bab7471f53f8f0aafb72e98ce2a`。这是资产管线与技术美术样本，不是全量商业成品，不涉及江岚录。

## 本批交付

三件原创几何设计：带五骨剑穗的长剑、漆木铜饰剑鞘、嵩山山门模块研究。
输出包括 3 MOD、2 STM、1 CHX、1 ANM、3 静态姿态 GLB、8 材质 DDS、4 个按钮状态 DDS、1 张拖尾 DDS、4 个运行用 WAV、2 个音乐分轨、乐谱与 JSON 网格/骨架源文件。
共 7 组台账资产、35 个列入哈希清单的文件。MOD/STM 是同一设计的格式版本，不算额外原创设计。

原生输出以当前 stm_static_model.cpp、anm_motion.cpp、chx_model.cpp 为契约，使用未修改的 C++ 解析器验证。没有把 GLB 改扩展名冒充原生文件。GLB 只包含静态姿态；动画/蒙皮保留在原生文件和可编辑源数据。

## 影响制作方向的实际发现

当前 MapKindInfo.bin 经仓库解码器解码，Map10 名称字段按 CP950 严格解码是「嵩山」；Map17 是「蘭州」。不是所有表都使用同一字符集：MapChange 的混合文本名称不作统一解码结论，连接按数字字段读取。

Map10 的 StaticNpc 当前记录包含 2010=(18555,29614)、1017=(46973,4198)、1018=(3092,47560)。MapChange 保存 8 条涉及 Map10 的双向记录，对端包括 Map2（泰山南麓）、Map70（少林寺）以及 Map79/82；后两者在当前 MapKindInfo 中没有名称，活动状态未证实，不能静默删除。这些锚点和记录未改动。

已读取的 81 份独立 HFL 均能由当前占位生成器逐字节重现。包括独立 10.hfl：16×16、2500×2300、SHA256 e24de771dca4a44da03baea1a284c1717ba10d9134db1365e590f39f47aa849f。

通过 Git LFS 真实取得 Map.pak，SHA256 b3b4c8e504877afaa1636f9a9e7ec88f187246a525b0004ea0f5a9268a0effb0。只读提取其中 10.hfl：1,188,682 字节，513×513 高度样本，51200×51200 原坐标范围，SHA256 a774fc78a439afe0b435b88a562ede471af013d731b7f10c1c1f2a402e2aa454。当前 C++ HFL 解析器得到同样尺寸。该原件仅作参考，未加入原创资产包，也未覆盖任何运行文件。

因此不能用独立占位地形作为原地图轮廓，更不能将 NPC 坐标缩放到错误尺寸上。下一阶段按真实地形契约约束新场景，验证加载优先级、地面接触与路径，再绑定新表现。

## 验收边界

Python 测试、原生解析检查与独立三维审阅都不等于 DX11 游戏验收。本批没有完成 Windows 游戏登录、装备显示、地面接触、多人技能、音频事件或手机真机测试。

原资源、协议、数值与默认资源档保持原样；moxiang-reart-v1 是离线生产资源档，尚未激活到客户端。所有样本处于 authored，正式发布默认被阻止。不能以 7 组样本冒充全量覆盖。

浏览器审阅器显示真实源网格，支持旋转/缩放；无 WebGL 时使用明确标注的 CPU 三维投影。它不是完整游戏，也不是原客户端截图。
