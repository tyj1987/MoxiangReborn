# Moxiang Art Source

This directory is the editable source-of-truth boundary for Asset Reset V2.

- Blender/: editable Blender scenes, high/low source and exporter tooling.
- Textures/: editable texture sources, masks and bake inputs.
- Concept/: approved concepts, paintovers and reference sheets.
- Animation/: animation authoring/interchange source.
- Audio/: editable source audio and stems.

Do not copy .blend working files into the Unity Assets tree. Unity receives reviewed runtime exports under unity/MoxiangClient/Assets/Moxiang/ArtV2/.

Legacy assets remain reference/provenance inputs and are not silently overwritten by this directory.
