## 证据等级

| 等级 | 定义 |
|---|---|
| E0 | 文件/包字节与 SHA-256 已记录 |
| E1 | 格式完整解码、字段覆盖完整 |
| E2 | 运行对象实例化且无缺依赖 |
| E3 | 运行时渲染或播放资源 |
| E4 | 正确玩家动作触发资源及状态变化 |
| E5 | 真实旧版对照与人工审查通过 |

自动测试、脚本 GUI、截图、parser/CTest 总数都不能单独证明 E5 或用户本人验收。E0–E5 是证据等级，不代表功能完成比例。
