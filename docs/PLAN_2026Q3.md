## 7. 工作规范（沿用 AGENTS.md）

- **1 commit = 1 模块/1 bug fix**：commit message `模块: 简述`
- **每 commit 前必跑**：`cmake --build modern/build --config Debug` 0 错 + `ctest -C Debug` 全过
- **每周末 gate**：ctest 全过 + 当周交付物就位
- **不动**：墨香【源码】/`、`[CC]Header/`、资源、协议头、老 exe
- **临时文件**：放 `modern/scratch/<date>-<topic>/`，不放根目录
- **每周一更新**：`modern/CODE_METRICS.md` 追加 snapshot
- **每周一更新**：`ROADMAP.md` §2 现状表

### 7.1 CMake 注册规范

所有新 test CMakeLists 必须用 `${CMAKE_SOURCE_DIR}`，绝不用绝对路径。

### 7.2 Build 触发规范

PowerShell PATH 处理 bug → 用 Python 包装：
```python
env = {}
for k, v in os.environ.items():
    if k.lower() == 'path': env['PATH'] = v
    elif k.upper() != 'PATH': env[k] = v
cmd = [r'C:\Program Files\CMake\bin\cmake.exe', '--build', r'C:\moxiang\modern\build', '--config', 'Debug']
subprocess.run(cmd, env=env, check=True)
```

### 7.3 Patch 规范（避免 PowerShell heredoc 转义）

- 用 `Path.read_bytes()` / `write_bytes()` 写 EUC-KR / CRLF 文件
- 写 CMake 内容时 `$` 必须 `chr(36)` = `\x24`
- 用 Python 脚本 + 三引号字符串避免转义
